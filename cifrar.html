Cifrar el panel con contraseña

  1. Elige el simulador-regatas.html (el panel sin cifrar).
  2. Escribe la contraseña dos veces. Mejor una frase de 4 o 5 palabras: el archivo cifrado es público y una contraseña corta se puede adivinar.
  3. Se descarga index.html, cifrado. Ese es el que subes a GitHub Pages; el otro, nunca.

Todo se hace en este navegador: ni el panel ni la contraseña salen de tu ordenador.
